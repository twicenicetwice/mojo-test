# Размещение Mojo Mobile

Это статический сайт: HTML, CSS, JavaScript и локальные ресурсы. Node.js, npm, сборка, база данных и сервер приложений для работы не нужны.

1. Загрузите index.html, styles.css, polish.css, app.js и папку assets в папку сайта, сохранив структуру.
2. Откройте сайт через HTTPS. Защищённое соединение нужно для Clipboard API; без него посетитель увидит инструкцию скопировать код вручную.
3. Не меняйте имена файлов и вложенность assets. Сервер должен отдавать CSS/JS/PNG/WebP/SVG/TTF с соответствующими MIME-типами.
4. Рекомендуется включить gzip/Brotli для HTML, CSS, JS, SVG. HTML лучше обновлять через Cache-Control: no-cache; ресурсы кэшировать с учётом версий.
5. Размещайте рекламный лендинг в корне домена `/`: адаптер маркетинговых ссылок не активируется в подпапке. Сам интерфейс работает и в подпапке. Специальные rewrite-правила не нужны. Проверка проводилась через HTTP-сервер, а не двойным кликом по HTML.

Функции: каталог 200 стран, поиск, меню, FAQ, календарное событие Google Calendar / .ics. Напоминание сохраняется самим пользователем; серверная отправка сообщений не реализована. Покупка, авторизация и оплата выполняются во внешнем магазине или Telegram.

Ссылки магазина находятся в app.js и данных embedded-catalogue в index.html. Все внешние ссылки открываются в новой вкладке. Страны и названия сохранены из предоставленного каталога; синхронизации с API нет, цены не показываются.

Совместимость: современные браузеры с HTMLDialogElement, CSS Grid и IntersectionObserver. Проверена Chromium-реализация на компьютере, планшетных и мобильных размерах. Реальные Safari/iOS и Firefox в текущем окружении не тестировались.

assets содержит лицензии сторонних библиотек. Логотип получен с официального сайта Mojo Mobile, шрифты — из исходных материалов. Подключён существующий счётчик Яндекс.Метрики 112642953 и адаптер https://app.mojomobile.ru/marketing/landing-attribution.js?v=47-02-3. Покупочные ссылки размечены data-mojo-channel и data-mojo-country. Один параметр m длиной 8–32 символа (латинские буквы, цифры, дефис, подчёркивание) передаётся в магазин и Telegram Mini App, в том числе из календарного напоминания. При отсутствии или некорректном m работают обычные покупочные ссылки. UTM-метки по-прежнему сохраняются для обычных ссылок магазина; при валидном m используется схема адаптера. Активность маркетингового кода проверяет приложение. Поддержка и проверка устройств не размечены как покупочные ссылки. Домен и sitemap/canonical настраиваются после выбора окончательного адреса размещения.
